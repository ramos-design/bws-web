# Fotky techniky

Sem nahrajte fotky vybavení používaného na webu. Stránka očekává tyto dva soubory:

| Soubor                  | Co na fotce má být              |
|-------------------------|---------------------------------|
| `fekalni-vuz.jpg`       | Zelený fekální vůz Rioned 1,5 m³ |
| `tlakovy-cistic.jpg`    | Žlutý tlakový čistič Rioned     |

## Jak je nahrát přes web (nejjednodušší)

1. Otevřete repozitář na GitHubu → složku `images/`.
2. Klikněte na **Add file → Upload files**.
3. Přetáhněte obě fotky (přejmenujte je přesně na názvy výše — případně po nahrání pomocí tužky).
4. Dole klikněte **Commit changes**.

Hotovo — web se sám aktualizuje (pokud máte GitHub Pages, build proběhne do ~2 minut).

## Doporučení

- Formát **JPG**, šířka kolem **1600 px**, kvalita 75–85 % (cca 200–400 kB).
- Bez textových overlayů na fotce — popisky řeší samotná stránka.
- Pokud chcete přidat další fotky, řekněte si o úpravu sekce „Naše technika" v `index.html`.
